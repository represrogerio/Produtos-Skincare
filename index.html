✏️ Editar Custo Manualmente

💡 Se deixar R$ em branco, será calculado automaticamente pela cotação atual ()

🔄 Sincronizar SKU / ML ID

Cole abaixo os dados da planilha Excel no formato:
Nome do Produto ⇥ ml_item_id ⇥ SKU (separados por TAB ou ; ou ,)

⚠️ Duplicidades serão mescladas automaticamente. Estoque do primeiro produto encontrado será mantido (somando dos duplicados).

⚙️ Configurar Mercado Livre

Para atualizar o estoque automaticamente, você precisa das credenciais da sua aplicação no Mercado Livre Developers.

💡 Atenção: a API do ML pode bloquear chamadas diretas do navegador (CORS). Se a sincronização falhar por isso, use um backend/proxy.
⏱️ Access Token expira em ~6 horas | Refresh Token expira em ~6 meses (política atual do ML)

✏️ Corrigir Nome do Produto

Digite o nome correto abaixo. O histórico e custos serão mantidos.

🏷️ Editar SKU / ML ID

Preencha os identificadores do produto. O ML ID é usado para sincronizar estoque com o Mercado Livre.

ℹ️ Para encontrar o ML ID: abra o anúncio no ML → o número final da URL é o ID. Números puros recebem prefixo MLB automaticamente.

🖼️ Alterar Imagem do Produto

Cole a URL da imagem ou faça upload de uma nova imagem (evite arquivos muito grandes no Firestore).
